# 🎓 Dự đoán điểm số kết quả học tập của học sinh (G3)

Ứng dụng web được xây dựng bằng **Streamlit** chạy mô hình **Linear Regression** giúp dự đoán kết quả điểm thi cuối kỳ G3 dựa trên đặc tính học sinh và điểm quá trình G1 & G2.

## 🛠️ Tính năng chính
- **Tải lên dữ liệu:** Nhập file Excel trực tiếp mà không cần cấu hình database phức tạp.
- **Trực quan hóa:** Hiển thị biểu đồ hệ số quan trọng Beta và biểu đồ sai số trực tiếp.
- **Công cụ dự báo:** Nhập thông tin học sinh thực tế qua giao diện trượt thông minh để xem kết quả điểm số dự báo.
